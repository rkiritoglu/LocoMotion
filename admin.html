🌍 GitHub Pages ile Ücretsiz Yayınlama

Sitenizi tüm dünyanın okuyabileceği canlı bir web sitesine dönüştürmek çok kolay:

  1. GitHub'da locomotion adında yeni bir depo (repository) oluşturun.
  2. API sekmesinden GitHub Depo Adınızı ve Token'ınızı girip kaydedin.
  3. Yukarıdaki "Şimdi GitHub'a Gönder" butonuna basın.
  4. GitHub deponuzda Settings ➔ Pages sekmesine gidin.
  5. Source kısmından "Deploy from a branch" ve main / (root) seçip Save deyin.
  6. Siteniz birkaç saniye içinde https://kullanici-adiniz.github.io/locomotion/ adresinde yayında olacaktır!
